# 📅 Booking Bot MVP - Полный Overview

## 🎯 Миссия

Создать рабочий MVP Telegram-сервиса онлайн-записи для независимых мастеров (лэшмейкеры, бровисты, парикмахеры и т.д.) — полностью на Python с безопасной системой бронирования и защитой от race conditions.

## 🎯 Основные особенности

1. **Персональные ссылки для мастеров**
   - Каждый мастер получает уникальный URL: `http://..../book/anna-abc123`
   - Делится с клиентами через Telegram или соцсети

2. **Безопасное бронирование**
   - Защита от одновременного бронирования одного слота двумя клиентами
   - Использует UNIQUE constraint + SELECT FOR UPDATE
   - Все операции в транзакциях БД

3. **Гибкое расписание**
   - Рабочие часы на день недели (пн-вс)
   - Перерывы и выходные дни
   - Автоматический расчёт доступных слотов

4. **Удобный интерфейс**
   - Выбор услуги → дата → время → подтверждение
   - 4 шага до готовой записи
   - Показывает цену и длительность

5. **Управление записями**
   - Отмена (освобождает слот)
   - Перенос на другое время
   - История всех операций

Все endpoints готовы к использованию:

```
POST   /api/masters/register           - Регистрация мастера
GET    /api/masters/me                 - Профиль мастера
POST   /api/services                   - Создание услуги
POST   /api/work-schedules             - График работы
POST   /api/bookings                   - Создание записи
GET    /api/available-slots/{slug}     - Доступные слоты
POST   /api/bookings/{id}/cancel       - Отмена записи
POST   /api/waitlist                   - Лист ожидания
+ ещё 7 endpoints...
```
